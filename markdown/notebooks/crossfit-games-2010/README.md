# 2010 CrossFit Games

Held July 16–18, 2010 at the Home Depot Center in Carson, California — the first year the Games moved out of Aromas to a large stadium. Graham Holmberg and Kristan Clever won the individual titles; CrossFit Fort Vancouver won the team competition.
