# 2011 CrossFit Games

Held July 29–31, 2011 at the Home Depot Center in Carson, California. Rich Froning Jr. and Annie Thorisdottir won the individual titles — the first of Thorisdottir's back-to-back championships and the start of Froning's run of four consecutive titles.
