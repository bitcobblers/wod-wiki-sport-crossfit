# 2023 CrossFit Games

Held August 3–6, 2023 at the Alliant Energy Center in Madison, Wisconsin — the final year of the Games' six-year run in Madison. First-time champions Jeffrey Adler and Laura Horvath were crowned Fittest on Earth; CrossFit Invictus won the team competition. Tia-Clair Toomey sat out the season on pregnancy.
