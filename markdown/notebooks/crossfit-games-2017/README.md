# 2017 CrossFit Games

Held August 3–6, 2017 at the Alliant Energy Center in Madison, Wisconsin — the first year of a six-year run in Madison. Mat Fraser defended his men's title and Tia-Clair Toomey won the first of her record-setting titles.
