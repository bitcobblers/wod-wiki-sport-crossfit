# 2012 CrossFit Games

Held July 11–15, 2012 at the Home Depot Center in Carson, California, with one day of competition at Camp Pendleton — the only year the Games included a military-base venue. Rich Froning Jr. and Annie Thorisdottir defended their individual titles; Hacks Pack UTE won the team competition.
