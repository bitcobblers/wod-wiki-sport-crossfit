# 2007 CrossFit Games

The inaugural CrossFit Games, held June 30–July 1, 2007 at the CrossFit Ranch ("The Ranch") in Aromas, California. Dave Castro and Greg Glassman staged the first "WOD Games" with athletes drawn from the affiliate community; workouts were pulled at random from a hopper. James Fitzgerald and Jolie Gentry were crowned the first Fittest on Earth.
