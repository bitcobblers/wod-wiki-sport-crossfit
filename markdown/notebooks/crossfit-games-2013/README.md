# 2013 CrossFit Games

Held July 26–28, 2013 (with the masters competition opening the week on July 24) at the StubHub Center in Carson, California. Rich Froning Jr. won his third consecutive title, matching the emerging standard for dominance; Sam Briggs won the women's competition.
